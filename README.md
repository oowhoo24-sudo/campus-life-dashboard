# 🏫 인문사회대 캠퍼스 생활 실태 분석 WebApp 🎓

파이썬을 처음 배우는 1학년이 만든, 인문사회대 학생들의 학교생활 만족도와 라이프 스타일을 분석하는 귀여운 Streamlit 웹앱 프로젝트입니다! 🌸

---

## ✨ 주요 기능 (Features)
1. **학과별 선택 필터**: 원하는 학과를 골라서 맞춤형 결과를 확인할 수 있어요.
2. **이상치/누락 데이터 정제**: 무응답이나 잘못된 데이터(2건)를 안전하게 제외하고 정제된 건수를 안내해 줍니다.
3. **생활 시간 비중 (원 그래프 🍩)**: 하루 평균 수면, 공부, 스마트폰 사용 시간의 비중을 파스텔톤 원 그래프로 보여줍니다.
4. **공부시간 vs 만족도 (산점도 📈)**: 공부 시간에 따른 학교생활 만족도의 관계를 시각화합니다.
5. **한 줄 의견 심층 분석 (클라우드 & 통계 ☁️📊)**: 
   - 솔직담백한 한 줄 의견을 **워드클라우드**로 시각화합니다.
   - 자주 등장하는 핵심 단어 **TOP 10 막대그래프**를 제공합니다.
   - 문장 내 키워드 매칭을 통해 **긍정/부정 감성 단어 등장 횟수**를 비교 분석해 줍니다.

---

## 🛠️ 사용 기술 및 라이브러리 (Tech Stack)
* **Python**
* **Streamlit** (웹앱 프레임워크)
* **Pandas** (데이터 전처리)
* **Matplotlib & Seaborn** (데이터 시각화)
* **WordCloud** (텍스트 마이닝)
